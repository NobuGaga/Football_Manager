## 十、评分模型（快速计算）

### 评分规则
```
基础分0
+ 联赛分:
  解放者杯 +5, 西甲/英超/沙职 +2, 德甲/法甲/日职 +0.5
  意甲 0, 韩职/瑞超 -0.5, 挪超 -1, 芬超/葡超/英冠 -1.5, 德乙/荷乙 -1
+ 赔率分:
  结果赔率<1.5 +4, <2.0 +2, >4.0 -5
+ 赔率差分:
  赔率差>5.0 +3, >3.0 +1, <0.8 -3
+ 进球分:
  预测总进球2-3球 +3, ≥5球 -4
+ 比分分:
  首选1:1/1:0/2:1/2:0 +2, 首选0:0/3:3 -2
+ 让球分:
  让球-1/+1 +1, 让球-2 -1
+ 时间分:
  上午场次 +1.5
```

## 十三、核心规律总结

1. **命中率与爆冷率强负相关**（相关系数-0.422）
2. **上午场次命中率是晚间的2倍**（62.5% vs 30.2%）
3. **赔率差>5.0时命中率显著提升**（40.8%）
4. **预测平局方向最准**（65.2%方向匹配率）
5. **让球-1押让负(53.7%)，让球+1押让胜(55.4%)**
6. **不存在热手效应**（命中后31.7% vs 未命中后32.0%）
7. **AI命中率持续提升**（早期31.7% → 后期35.0%）
8. **实际2球/3球时命中率最高**（50%/56.4%）
9. **实际大球(>2.5)时命中率仅24.2%**
10. **主胜/平局比值>2.0时100%不爆冷**

## 十四、每日行动清单

### Step 1: 联赛筛选
- [ ] 解放者杯 → 直接纳入
- [ ] 西甲/英超/沙职 → 优先纳入
- [ ] 意甲/法甲/瑞超 → 条件纳入
- [ ] 葡超/芬超/英冠/德乙 → 排除

### Step 2: 赔率检查
- [ ] 结果赔率<1.5 → 高价值
- [ ] 结果赔率1.5-2.5 → 检查其他条件
- [ ] 结果赔率>4.0 → 排除

### Step 3: 赔率结构检查
- [ ] 赔率差>5.0 → 加分
- [ ] 赔率差<0.5 → 排除（爆冷率64.7%）
- [ ] 三档接近 → 小爆/大爆概率高

### Step 4: 预测比分检查
- [ ] 首选1:1/2:1/2:0/1:0 → 加分
- [ ] 首选0:0/3:3 → 减分
- [ ] 总进球预测2-3球 → 加分
- [ ] 总进球预测≥5球 → 排除

### Step 5: 时间段检查
- [ ] 上午6-12点 → 加分
- [ ] 晚间18-24点 → 谨慎

### Step 6: 让球盘参考
- [ ] 让球-1 → 考虑让负
- [ ] 让球+1 → 考虑让胜

### Step 7: 评分计算
- [ ] >10分 → 必投（单关或3串1）
- [ ] 6-10分 → 重点（2串1或单关）
- [ ] 3-6分 → 可选（仅单关）
- [ ] <3分 → 不投

### Step 8: 预测位置选择
- [ ] 不爆冷场次 → 看1号位
- [ ] 小爆冷场次 → 看3号位
- [ ] 大爆冷场次 → 看1号位
- [ ] 赔率<1.5 → 看1号位
- [ ] 赔率>3.0 → 看3号位

### Step 9: 最终确认
- [ ] 没有避雷场景（赔率>4/葡超/总进球≥5）
- [ ] 至少满足2个加分项
- [ ] 混合过关不超过3场
