## 七、评分模型（V4校准版）

### 评分规则（V4校准版）
```
基础分0
+ 联赛分:
  解放者杯 +5, 西甲/英超/沙职 +2, 德甲/法甲/日职 +0.5
  意甲/欧冠/欧罗巴/欧协联 0, 韩职/瑞超/荷甲 -0.5
  挪超 -1, 芬超/葡超/英冠 -1.5, 德乙/荷乙 -1
  澳超/美职/亚冠 0
+ 赔率分:
  结果赔率<1.5 +4, <2.0 +2, >4.0 -5
+ 赔率差分:
  赔率差>5.0 +3, >3.0 +1, <0.8 -3
+ 进球分:
  预测总进球2-3球 +3, >=5球 -4
+ 比分分:
  首选1:1/1:0/2:1/2:0 +2, 首选0:0/3:3 -2
+ 让球分:
  让球-1/+1 +1, 让球-2 -1
+ 时间分:
  上午场次 +1.5
+ 胜负平差分:
  主胜-平局>2 +2
```

## 十三、每日行动清单（V4更新）

### Step 1: 联赛筛选
- [ ] 解放者杯 → 直接纳入
- [ ] 西甲/英超/日职 → 优先纳入
- [ ] 沙职/意甲/瑞超/芬超 → 条件纳入
- [ ] 葡超/挪超/德甲/德乙/英冠 → 排除（除非偏态套利）

### Step 2: 赔率检查
- [ ] 结果赔率<1.5 → 不再自动高价值（实际命中率仅29.7%）⚠️
- [ ] 结果赔率1.5-2.0 → 需结合其他条件（实际命中率31.4%）⚠️
- [ ] 结果赔率2.0-2.5 → 检查其他条件（实际命中率35.4%）
- [ ] 赔率差<0.5 → 特殊场景（64.3%命中率，必投）

### Step 3: 时间段检查
- [ ] 上午6-12点 → 加分（命中率59.5%）
- [ ] 晚间18-24点 → 谨慎（命中率31.3%）

### Step 4: 预测比分检查
- [ ] 首选1:1+次选1:2 → 高价值组合（60.0%）
- [ ] 首选1:1+次选1:0 → 可选组合（55.6%）
- [ ] 首选2:0/2:1 → 降权（过度预测，效率26-34%）⚠️

### Step 5: 评分计算（V4校准）
- [ ] 6-10分 → 最佳区间（37.8%，单关或2串1）
- [ ] >10分 → 不再自动必投（实际30.4%）⚠️
- [ ] 3-6分 → 可选（31.3%，仅单关）
- [ ] <0分 → 不再自动避雷（实际22.2%）⚠️

### Step 6: 最终确认
- [ ] 没有避雷场景（葡超/挪超/德甲/总进球>=5）
- [ ] 至少满足2个加分项
- [ ] 混合过关不超过3场
- [ ] 保持固定注码，不因连中/连不中调整
