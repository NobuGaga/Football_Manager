```
基础分0
+ 联赛分: 解放者杯+5, 西甲/英超/沙职+2, 日职+1, 德甲/法甲/意甲/挪超0
  韩职/瑞超/荷甲-0.5, 芬超/葡超/英冠-1.5, 德乙-1

+ 赔率差分: >5.0 +3, >3.0 +1, <0.8 -3, <0.5 +5
+ 进球分: 首选总进球2 +3, =3 +1, >=5 -4
+ 比分分: 首选1:1/1:0/2:0/3:0 +2, 首选0:0/3:3 +2(V4新增补漏)
          首选2:1 -1(V4新增降权), 首选0:0/3:3/4:1/3:2备选+1
+ 让球分: 让球-1/+1 +1, 让球-2 -1
+ 时间分: 上午+1.5, 凌晨+0.5(V4新增)
+ 胜负平差分: 主胜-平局>2 +2
```

## 十、每日行动清单（精简版）

**Step 1: 联赛筛选**
- 解放者杯/英超凌晨 → 🟢直接纳入
- 葡超/挪超/德甲 → 🔴排除（但葡超可偏态套利）

**Step 2: 赔率检查**
- 结果赔率<2.0 → 🟢高价值
- 结果赔率>4.0 → 🔴排除

**Step 3: 比分检查**
- 首选为1:1 → 查速查表确认联赛是否支持
- 首选为2:1 → ⚠️降权（过度预测效率低）
- 首选1:1 → 次选必带0:0（补漏）

**Step 4: 时间段**
- 上午 → +1.5分（命中率61%）
- 晚间 → -1分（命中率31%）

**Step 5: 评分计算**
- >6分 → 🟢必投
- <3分 → 🔴不投

**Step 6: 双选优化**
- 首选1:1时，次选优先1:2 > 1:0 > 0:0
- 让球-2时，次选加入4:0/4:1

**Step 7: 最终确认**
- 至少满足2个加分项
- 混合过关不超过3场
- 固定注码，不因连中/连不中调整
