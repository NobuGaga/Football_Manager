### 评分规则
```
基础分0
+ 联赛分:
  解放者杯 +5, 西甲/英超/沙职 +2, 德甲/法甲/日职 +0.5
  意甲/欧冠/欧罗巴/欧协联 0, 韩职/瑞超/荷甲 -0.5
  挪超 -1, 芬超/葡超/英冠 -1.5, 德乙/荷乙 -1
  澳超/美职/亚冠 0
+ 赔率分:
  结果赔率<1.5 +4, <2.0 +2, >4.0 -5
+ 赔率差分:
  赔率差>5.0 +3, >3.0 +1, <0.8 -3
+ 进球分:
  预测总进球2-3球 +3, ≥5球 -4
+ 比分分:
  首选1:1/1:0/2:1/2:0 +2, 首选0:0/3:3 -2
+ 让球分:
  让球-1/+1 +1, 让球-2 -1
+ 时间分:
  上午场次 +1.5
```

## 十三、核心规律总结

1. **命中率与爆冷率强负相关**（相关系数约-0.42）
2. **上午场次命中率是晚间的2.1倍**（63.0% vs 30.2%）
3. **赔率差>5.0时命中率显著提升**（35.6%）
4. **预测平局方向最准**（1:1首选命中率20.8%，远高于平均11.2%）
5. **让球-1押让负(53.4%)，让球+1押让胜(55.6%)**
6. **不存在热手效应**（命中后31.7% vs 未命中后32.0%）
7. **AI命中率持续提升**（早期31.7% → 后期35.0%）
8. **实际2球/3球时命中率最高**（总进球2球时约35%，3球时约38%）
9. **实际大球(>2.5)时命中率仅30.9%**，小球时33.5%
10. **主胜赔率≥4时命中率反而高达47.1%**（反直觉高价值区）
11. **首选1:1+次选1:2组合命中率61.1%**（最佳组合）
12. **葡超/挪超/德甲为三大低命中率联赛**（<20%）

## 十四、每日行动清单

### Step 1: 联赛筛选
- [ ] 解放者杯 → 直接纳入
- [ ] 西甲/英超/沙职 → 优先纳入
- [ ] 意甲/法甲/日职/瑞超 → 条件纳入
- [ ] 葡超/挪超/德甲/德乙/英冠/芬超 → 排除

### Step 2: 赔率检查
- [ ] 结果赔率<1.5 → 高价值
- [ ] 结果赔率1.5-2.5 → 检查其他条件
- [ ] 结果赔率>4.0 → 排除（但主胜≥4可例外）

### Step 3: 赔率结构检查
- [ ] 赔率差>5.0 → 加分
- [ ] 赔率差<0.5 → 排除（爆冷率66.3%）
- [ ] 三档接近 → 小爆/大爆概率高

### Step 4: 预测比分检查
- [ ] 首选1:1/1:0/2:1/2:0 → 加分
- [ ] 首选0:0/3:3 → 减分
- [ ] 总进球预测2-3球 → 加分
- [ ] 总进球预测≥5球 → 排除
- [ ] 首选1:1+次选1:2 → 高价值组合

### Step 5: 时间段检查
- [ ] 上午6-12点 → 加分（命中率63%）
- [ ] 晚间18-24点 → 谨慎（命中率30%）

### Step 6: 让球盘参考
- [ ] 让球-1 → 考虑让负（53.4%概率）
- [ ] 让球+1 → 考虑让胜（55.6%概率）

### Step 7: 评分计算
- [ ] >6分 → 必投（单关或2-3串1）
- [ ] 3-6分 → 可选（仅单关）
- [ ] <3分 → 不投

### Step 8: 预测位置选择
- [ ] 不爆冷场次 → 看1号位（17.1%）
- [ ] 小爆冷场次 → 看3号位（9.9%）
- [ ] 大爆冷场次 → 看1号位（10.6%）
- [ ] 赔率<1.5 → 看1号位
- [ ] 赔率>3.0 → 看2号位

### Step 9: 最终确认
- [ ] 没有避雷场景（赔率>4/葡超/挪超/德甲/总进球≥5）
- [ ] 至少满足2个加分项
- [ ] 混合过关不超过3场

## 十五、高爆冷率场景混合过关策略（新增）

> 统计口径：筛选历史数据中「小爆冷率 ≥ 40%」或「大爆冷率 ≥ 40%」的联赛与场景，分析其混合过关投注价值与数学期望（EV）。
> 模型假设：8场比赛全部来自同一场景，统一押注该场景下历史概率最高的结果方向。

### 15.1 核心结论

**在高爆冷率联赛中，跟随历史概率最高的结果类型做混合过关，EV比极高，多数场景EV比 > 2.0，最高可达18.0。**

这与直觉相反：AI命中率低的联赛（如葡超13%、德甲18.6%），恰恰是高价值混合过关的金矿——因为结果高度偏向某一类型（小爆冷或大爆冷），形成可预测的"偏态分布"。

### 15.3 策略原理：偏态分布套利

传统思维认为"高爆冷率 = 不可预测"，但数据揭示相反规律：

| 联赛 | AI命中率 | 小爆冷率 | 大爆冷率 | 结果集中度 | 套利空间 |
|------|----------|----------|----------|------------|----------|
| 葡超 | 13.0% | 60.9% | 13.0% | 小爆冷一家独大 | 极高 |
| 荷甲 | 28.6% | 14.3% | 42.9% | 大爆冷+不爆冷双高 | 高 |
| 法甲 | 27.6% | 41.4% | 13.8% | 小爆冷主导 | 高 |
| 英冠 | 28.6% | 21.4% | 42.9% | 大爆冷主导 | 高 |

**关键洞察**：AI命中率低不是因为"完全随机"，而是因为结果高度集中于某一冷门方向，而AI预测倾向于分散覆盖，导致偏离高概率方向。

### 15.4 最优模式选择

对于高EV场景，**4,5关模式EV比最高**，但需承担更高波动。稳健选择如下：

| 风险偏好 | 推荐模式 | 理由 |
|----------|----------|------|
| 稳健型 | 2,3关 | EV比仍>2.0，命中概率更高，资金曲线平滑 |
| 平衡型 | 3,4关 | EV比3-6倍，适中波动 |
| 激进型 | 4,5关 | EV比最高（如葡超18倍），但需中4场才获高奖 |

### 15.6 风险警示

1. **样本量风险**：法乙仅7场样本，EV计算置信度较低；葡超23场、法甲29场相对可靠。
2. **赔率漂移风险**：实际赔率可能与历史平均赔率偏离±20%，导致EV比波动。

4. **联赛变化风险**：赛季末/杯赛阶段球队战意变化，可能打破历史偏态分布。
