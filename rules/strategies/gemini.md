# Gemini｜情景分析策略

```json
{
  "ai_model": "gemini",
  "model_name": "Gemini",
  "strategy_id": "gemini-scenario-analysis-v1",
  "strategy_category": "情景分析"
}
```

这是项目定义的 Gemini 策略分类，不代表调用或验证任何外部 AI 服务。

- 基于本地比分概率分布，分别描述主胜、平局和客胜的主要情景。
- 同时展示最高概率方向与至少一个替代方向，避免只呈现单一结果。
- 比分参考来自已保存分布，不虚构阵容、伤停或实时消息。
- 数据完整度低时明确所有情景均为弱参考，不将探索性分析升级为投注建议。
- 后续复盘按联赛、样本量和概率校准评价，不以单次比分命中替代长期表现。
