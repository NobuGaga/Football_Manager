# 足球经理数据与预测规则手册

版本：V3  
更新日期：2026-10-25  
适用范围：官方对阵导入、赛前预测、每日报告、赛果核对与回测

## 一、分析范围与来源优先级

1. 仅分析中国体育彩票竞彩足球官方对阵中的比赛，不自行扩赛。
2. 手动保存的官方对阵文件是稳定输入；体彩官方公开接口是可降级的自动获取入口。
3. 专业数据源只补充赛前特征，不改变官方分析范围。
4. 自动获取不得绕过验证码、登录、访问控制或网站限制。
5. 无法唯一关联的比赛进入 `match_review_queue`，不得猜测后自动合并。

## 二、数据清洗

- 对阵双方必须能明确拆分，不允许使用“主队”“客队”等占位伪值。
- 开赛时间无法解析即报错；缺少日期时由调用者显式提供，禁止默认成当前时间。
- 数据库存 UTC 时间和执行时区，日报显示当地时间。
- 比分统一为无前导零的 `主队进球:客队进球`，例如 `01:02` 转为 `1:2`。
- 每次对阵导入按内容哈希保存快照；相同内容不重复插入，不同内容不覆盖旧快照。
- 重要特征必须带 `as_of` 和来源；预测只能读取预测时点已经存在且不晚于开赛的数据。

## 三、预测输出

每场输出：

1. 主胜、平局、客胜概率；
2. 双方预期进球；
3. 概率最高的 5 个准确比分及各自概率；
4. 数据完整度、缺失项和特征来源；
5. 分析依据、风险提示、模型版本和预测生成时间。

信息不足时使用降级模型并明确标记，不得把低完整度结果包装成高置信结论。杯赛、资格赛、小样本、伤停和阵容不确定时应降低结论强度或标记观望。

## 四、版本管理

- 首次预测保存赛前初版。
- 临场更新使用 `predict --refresh`，追加新记录而非覆盖初版。
- 模型参数存入 `model_versions`；改变参数或公式时必须新增模型版本。
- 旧版只有比分文本而没有概率的记录不得补造概率参加新版回测。

## 五、赛果核对

- 实际比分通过 `fixture_key` 或“编号＋双方＋日期”唯一关联。
- 完赛后记录实际比分、H／D／A 赛果、来源、录入时间和复盘备注。
- 准确比分命中分别统计首选和前三；同时统计胜平负方向命中。
- 延期、取消和未出赛果的比赛不得按 0:0 或负例处理。

## 六、回测规则

仅纳入 `input_as_of ≤ predicted_at ≤ start_time_utc` 的预测。按比赛时间排序，分别输出总体和分联赛结果。

核心指标：Log Loss、Brier 分数、概率校准、胜平负准确率、首选／前三比分命中率、预期进球 MAE。准确比分命中次数不能单独代表模型质量。

## 七、报告表达约束

- 不使用“包中”“稳赢”“必中”等确定性措辞。
- 历史命中率只描述对应样本，不外推为未来收益承诺。
- 每日报告必须保留风险提示和赛后待补录字段。
- 固定提醒：以上结果为概率分析，足球比赛存在不确定性，不构成收益保证或确定性投注建议。

旧版 V2 规则保存在 `docs/legacy/football_manager_rules_v2.md`，仅用于审计，不再驱动现行工程。
