# 足球经理的推断 · 微信小程序

这是“足球经理的推断”工程信息中心的原生微信小程序版本。五个标签页展示工程概览、数据流水线、模型与回测、每日自动化和工程结构。所有内容均为本地静态信息，不读取数据库、不执行仓库命令，也不包含凭证。

## 当前方式：本人测试号预览

当前使用已登录微信账号下的普通小程序测试号。本机私有配置和自用交付包已切换到该测试号；2026-11-07 已通过官方编译并生成预览二维码。使用开发者微信扫码即可体验，当前流程无需正式 AppID、代码上传私钥或正式发布资料。

操作说明见 [`自用预览说明.txt`](../delivery/wechat-miniprogram/publishing/自用预览说明.txt)。修改页面或预览入口失效时，在开发者工具中重新点击“预览”。真机上的页面显示和交互仍需本人验收。

## 本地导入与预览

1. 下载并安装当前 Stable 版微信开发者工具：<https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html>。
2. 打开“导入项目”，选择本 `miniprogram/` 目录，即包含 `project.config.json` 的这一层，不要选择仓库根目录。
3. 公共配置中的 `appid` 保留为 `touristappid` 占位；本机实际使用 `project.private.config.json` 中已绑定的普通小程序测试号。自用交付包则已将测试号写入包内的公共配置。
4. 账号类型必须选择“小程序”，不要选择“小游戏”，否则工具会要求 `game.json`。
5. 在开发者工具中编译并检查五个标签页、流程节点切换、命令模式切换、文件选择和复制功能。
6. 真机使用时，在开发者工具中登录当前测试号所属的微信账号，点击“预览”并扫码。本人测试以此入口使用。

真实 AppID 建议写入本机 `project.private.config.json`；该文件已被 `.gitignore` 排除，不要提交个人配置。

本机存在私有配置时，开发者工具优先使用其中的 AppID。为指定账号准备的交付包可以在包内 `project.config.json` 中绑定对应 AppID，导入后请核对“详情 → 基本信息”中的账号。

## Kimi Claw 本地体验版与预览

GitHub 只保存项目版本，不运行小程序上传或预览任务。需要更新时，由 Kimi Claw 在已配置好凭证的运行环境中调用官方微信 `miniprogram-ci`。

### 一次性配置

1. 安装 Node.js 22 或兼容版本，并在 `miniprogram/` 执行 `npm ci`。
2. 在微信公众平台进入“开发管理 → 开发设置 → 小程序代码上传”，由管理员生成代码上传密钥，并按平台要求配置出口 IP 白名单。
3. 确保自己的微信账号是该小程序的管理员、开发者或具有相应预览权限的成员。
4. 在 Kimi Claw 的安全运行环境中配置 `WECHAT_APPID` 和多行私钥 `WECHAT_PRIVATE_KEY`，不要写入仓库、脚本、命令参数或日志。
5. 如果启用了上传 IP 白名单，将 Claw 实际运行环境的固定出口 IP 加入白名单；不要为图方便关闭白名单。

### 上传并持续更新体验版

```bash
cd miniprogram
npm test
npm run upload
```

上传脚本固定默认使用 `CI 机器人 1`，避免更换上传身份后脱离已绑定的体验版。版本号默认为 `1.0.<UTC 时间戳>`，也可通过 `WECHAT_VERSION=x.y.z` 显式指定；`WECHAT_ROBOT` 可指定 1–30 的机器人编号，但为持续更新体验版不应随意更换。

首次使用时，上传成功后需在微信公众平台“管理 → 版本管理 → 开发版本”中，将 `CI 机器人 1` 提交的版本设为体验版。这个绑定只需完成一次；之后同一机器人上传新版本时会自动更新体验版。若更换机器人，需要重新绑定。

### 生成自用预览二维码

```bash
cd miniprogram
WECHAT_PREVIEW_OUTPUT="$PWD/../delivery/wechat-miniprogram/preview-ci.jpg" npm run preview
```

二维码由微信官方 `ci.preview` 生成并保存到上述本地路径，由有权限的微信账号扫码。该模式不会上传开发版本，也不会更新体验版；后续修改需要重新生成并扫描新的二维码。预览图片不要提交到仓库。

私钥只在运行环境的临时目录中生成，脚本结束后立即删除。密钥疑似泄露时，应立即在微信公众平台重置。

`npm test` 覆盖五个页面的主要切换、复制调用、上传机器人参数校验和本地版本号生成；它不能替代微信开发者工具的视觉检查和真机验收。没有真实环境凭证时不要运行 `npm run upload` 或 `npm run preview`。

## 自用与发布边界

“生成预览二维码”“上传开发版本”“设置体验版”“提交审核”“正式发布”是不同阶段。本工程面向自己的微信账号，Kimi Claw 可执行预览、上传和已绑定机器人的体验版持续更新；首次体验版绑定需要人工完成，不绕过账号授权，也不自动执行公开审核或正式发布。
